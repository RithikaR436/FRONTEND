Chapter 03

Primitive Data Types, Memory Stack & Immutability

A primitive value is data that is not an object and has no methods or properties of its own. Primitive values are immutable (cannot be altered) and stored directly in the Call Stack by value.

💡 சுருக்கம் (Summary in Tamil): Primitive data types என்பவை அடிப்படையான ஒற்றை மதிப்புகள் (Single values). இவை Stack Memory-ல் அவற்றின் நேரடி மதிப்புடனே (By Value) சேமிக்கப்படும். ஒரு முறை உருவாக்கப்பட்ட Primitive மதிப்பை மாற்றவே முடியாது (Immutable). ஒரு வேரியபிளுக்கு புதிய மதிப்பை கொடுக்கும் போது, பழைய மதிப்பு மாற்றப்படாமல் புதிய மதிப்பு மெமரியில் உருவாகும்!

3.1 Comprehensive Breakdown of the 7 Primitives

1 String (Textual Sequences)

Strings are sequences of 16-bit UTF-16 code units. Created with single quotes '...', double quotes "...", or template literals `...`. 

const greeting = "Hello, World!";
console.log(greeting.length);        // 13
console.log(greeting.charAt(0));      // "H"
console.log(greeting.slice(0, 5));    // "Hello"

2 Number (Double Precision Floating Point)

Unlike languages with int, float, and double, JavaScript has a single numeric type: 64-bit IEEE 754 floating point. Range is \(-(2^{53}-1)\) to \(2^{53}-1\) (Number.MAX_SAFE_INTEGER). Special numeric values include Infinity, -Infinity, and NaN. 

const integer = 42;
const floatVal = 3.14159;
console.log(1 / 0);                   // Infinity
console.log(0 / 0);                   // NaN
console.log(Number.isSafeInteger(9007199254740991)); // true

3 BigInt (Arbitrary Precision Integers)

Introduced in ES2020 to safely store and manipulate integers beyond Number.MAX_SAFE_INTEGER. Created by appending n to an integer literal or calling BigInt(). 

const hugeNumber = 9007199254740991n + 2n;
console.log(hugeNumber);              // 9007199254740993n
console.log(typeof hugeNumber);       // "bigint"

// Note: BigInt cannot be mixed with Number directly:
// const invalid = 10n + 5; // ❌ TypeError: Cannot mix BigInt and other types

4 Boolean (Logical Truth Values)

Contains only two literal values: true and false. Used extensively in control flow and logical evaluation. 

const isLoggedIn = true;
const hasAdminRights = false;
console.log(isLoggedIn && !hasAdminRights); // true

5 & 6 Undefined vs Null

Undefined: System-level default. A variable that has been declared but not assigned any value.
Null: Programmer-assigned value representing the intentional absence of an object or value. 
let uninitializedVar;
console.log(uninitializedVar);        // undefined

let emptySession = null;
console.log(emptySession);            // null

console.log(null == undefined);       // true  (Loose equality with coercion)
console.log(null === undefined);      // false (Strict equality: different types)

7 Symbol (Unique Identifiers)

Introduced in ES6, symbols are completely unique and immutable values often used as non-enumerable object property keys to avoid property name collisions. 

const sym1 = Symbol("secretId");
const sym2 = Symbol("secretId");

console.log(sym1 === sym2);           // false (Every Symbol() creates a unique entity)

const user = {
  name: "Karthik",
  [sym1]: "EncryptedToken#9901"
};

console.log(user[sym1]);              // "EncryptedToken#9901"
console.log(Object.keys(user));       // ["name"] (Hidden from normal key loops!)

3.2 Primitive Immutability in Memory

Primitives are immutable. You cannot mutate the content of a primitive value in place. When you perform string operations or number additions, JavaScript creates an entirely new primitive value in memory. 

let str = "hello";

// Attempting to mutate individual character
str[0] = "H"; // Silently fails in non-strict mode
console.log(str); // "hello" (Original string unchanged!)

// Reassignment creates a new string
str = str.toUpperCase();
console.log(str); // "HELLO" (New string allocated and assigned)

3.3 Autoboxing & Primitive Wrapper Objects

If primitives are not objects, how can we call "text".toUpperCase() or (42).toFixed(2)?

// What JavaScript engine does behind the scenes:
  1. Identifies method call on a primitive value: "code".toUpperCase()
  2. Autoboxing: Temporarily wraps the primitive in an Object wrapper: new String("code")
  3. Executes the method on the wrapper: String.prototype.toUpperCase.call(...)
  4. Immediately destroys the temporary wrapper object for garbage collection!
// Proof of temporary wrapper lifecycle:
let word = "javascript";
word.customTag = "frontend"; // Wrapper created, property attached, wrapper deleted!

console.log(word.customTag); // undefined (The temporary wrapper is already gone!)
