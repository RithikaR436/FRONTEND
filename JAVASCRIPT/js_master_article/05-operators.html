JavaScript Operators: Arithmetic, Equality, Short-Circuiting & Modern Safety

Operators perform mathematical computations, value comparisons, and conditional logic. Modern ECMAScript features revolutionary operators like Nullish Coalescing (??) and Optional Chaining (?.) for bulletproof code.

(Nullish Coalescing) மற்றும் ?. (Optional Chaining) போன்ற நவீன ஆபரேட்டர்கள் எரர்களைத் தவிர்க்க மிகவும் உதவுகின்றன!

5.1 Equality Operators: Loose (==) vs Strict (===)

The difference between loose equality and strict equality is one of the most tested topics in JavaScript:

Loose Equality (==)

Performs implicit type coercion if types differ before comparing values.

console.log(5 == "5");       // true (String "5" converted to number 5)
console.log(0 == false);     // true (false coerced to 0)
console.log("" == 0);        // true ("" coerced to 0)
console.log(null == undefined); // true (Special loose rule)

Strict Equality (===)

Compares both type AND value without performing any type coercion.

console.log(5 === "5");      // false (number !== string)
console.log(0 === false);    // false (number !== boolean)
console.log("" === 0);       // false (string !== number)
console.log(null === undefined); // false (null !== undefined)

5.2 Logical Operators & Short-Circuit Evaluation

Logical operators && (AND) and || (OR) don't always return boolean values—they return the actual operand value that determined the outcome!

Logical OR (||): Returns the first truthy operand, or the last operand if none are truthy. 
const displayName = userCustomName || "Guest User";
console.log("" || "Default");        // "Default" (Empty string is falsy)
console.log("Admin" || "Default");   // "Admin"   (First truthy found)
Logical AND (&&): Returns the first falsy operand, or the last operand if all are truthy. 
const user = { authenticated: true, role: "SuperAdmin" };
const accessGranted = user.authenticated && user.role;
console.log(accessGranted); // "SuperAdmin"

5.3 Modern Safety: Nullish Coalescing (??) & Optional Chaining (?.)

1. || vs ?? (The Zero & False Bug)

|| treats 0, "", and false as falsy, causing accidental overwrites! ?? checks strictly for null or undefined. 

const userScore = 0; // Valid game score!

// Problem with ||
const result1 = userScore || 50;
console.log("Using || :", result1); // 50 ❌ (Overwrote valid score 0!)

// Fixed with Nullish Coalescing ??
const result2 = userScore ?? 50;
console.log("Using ?? :", result2); // 0  ✅ (Preserves 0!)

2. Optional Chaining (?.)

Safely accesses nested properties without throwing Uncaught TypeError: Cannot read properties of undefined. 

const order = {
  id: 4021,
  customer: {
    name: "Suresh"
    // address is missing!
  }
};

// Safe property access:
console.log(order.customer?.address?.zipCode); // undefined (No crash!)

// Safe method call:
order.printReceipt?.(); // Safe: does nothing if method doesn't exist!

// Safe array indexing:
const items = null;
console.log(items?.[0]); // undefined

5.4 Ternary, Unary & Relational Operators 

// 1. Ternary Operator (condition ? ifTrue : ifFalse)
const age = 20;
const status = age >= 18 ? "Adult" : "Minor";
console.log(status); // "Adult"

// 2. Unary Plus (fast string-to-number conversion)
const numericString = +"450";
console.log(typeof numericString, numericString); // "number", 450

// 3. 'in' operator (checks if key exists in object or prototype)
console.log("name" in { name: "Aravind" }); // true

// 4. 'instanceof' operator (checks prototype chain)
console.log([] instanceof Array);  // true
console.log([] instanceof Object); // true
