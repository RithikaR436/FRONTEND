JavaScript Engine Architecture at a Glance

How V8 / SpiderMonkey parses, allocates memory, and executes code

1. Call Stack (Stack Memory)

Handles function execution frames and primitive variable storage. Follows LIFO (Last-In-First-Out). Fast direct access memory allocation.

2. Memory Heap (Dynamic Memory)

Unstructured pool where non-primitive reference data types (Objects, Arrays, Functions) live. Referenced via memory pointers stored in the stack.

3. Event Loop & Web APIs

Coordinates asynchronous non-blocking I/O, Promises (Microtask Queue), and DOM/Timers (Macrotask Queue) back onto the single-threaded Call Stack.
