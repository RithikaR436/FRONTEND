ES6+ Modern JavaScript: Arrow Functions, Destructuring, Spread, Classes & Async

ECMAScript 2015 (ES6) was the most significant update in JavaScript history. It transformed JavaScript from a simple scripting language into an enterprise-grade platform.

💡 சுருக்கம் (Summary in Tamil): ES6 (ECMAScript 2015) ஜாவாஸ்கிரிப்டில் நவீன புரட்சியை ஏற்படுத்தியது. Arrow Functions (Lexical this), Destructuring (தரவுகளை எளிதாக பிரித்தெடுத்தல்), Spread/Rest ஆபரேட்டர்கள் (...), Classes, Modules, மற்றும் Promises/Async-Await போன்ற அம்சங்கள் கோடை மிகச் சுருக்கமாகவும், சுத்தமாகவும் எழுத உதவுகின்றன!

8.1 Arrow Functions & Lexical this Binding

Arrow functions provide clean syntax with implicit returns, and they do NOT bind their own this, arguments, or prototype: 

// 1. Syntax Comparison:
const square = x => x * x; // Concise implicit return
console.log(square(5));   // 25

// 2. Lexical 'this' resolution inside Objects & Timers:
const timerApp = {
  seconds: 0,
  start() {
    // Arrow function inherits 'this' from start() method!
    setInterval(() => {
      this.seconds++;
      // console.log("Current seconds:", this.seconds);
    }, 1000);
  }
};

8.2 Destructuring Assignment

Object Destructuring

const user = {
  fullName: "Rithika",
  age: 22,
  location: { city: "Trichy" }
};

// Aliasing (fullName: name) + Defaults + Nested
const { fullName: name, location: { city }, role = "Developer" } = user;

console.log(name, city, role); // "Rithika", "Trichy", "Developer"

Array Destructuring

const colors = ["#FF0000", "#00FF00", "#0000FF"];

// Basic destructuring & skipping indices
const [primary, , tertiary] = colors;
console.log(primary, tertiary); // "#FF0000", "#0000FF"

// Variable Swapping in 1 line!
let a = 1, b = 2;
[a, b] = [b, a];
console.log("Swapped:", a, b); // 2, 1

8.3 Rest Parameter vs Spread Operator (...)

Rest Operator: Gathers into Array

// Collects indefinite arguments into an Array
function sumAll(multiplier, ...numbers) {
  return numbers.reduce((acc, n) => acc + (n * multiplier), 0);
}
console.log(sumAll(2, 10, 20, 30)); // 120

Spread Operator: Expands Iterables

const arr1 = [1, 2];
const arr2 = [3, 4];
const combined = [...arr1, ...arr2, 5];
console.log(combined); // [1, 2, 3, 4, 5]

const baseUser = { id: 1 };
const activeUser = { ...baseUser, active: true };
console.log(activeUser); // { id: 1, active: true }

8.4 ES6 Classes & Object-Oriented JavaScript

Classes in JavaScript are syntactic sugar built on top of prototypal inheritance, featuring constructors, inheritance with extends / super, and private class fields (#): 

class Employee {
  #salary; // Private field (ES2022)

  constructor(name, salary) {
    this.name = name;
    this.#salary = salary;
  }

  getSalary() {
    return `$${this.#salary.toLocaleString()}`;
  }
}

class Manager extends Employee {
  constructor(name, salary, department) {
    super(name, salary); // Calls parent constructor
    this.department = department;
  }

  getSummary() {
    return `${this.name} leads ${this.department} with budget ${this.getSalary()}`;
  }
}

const lead = new Manager("Anitha", 120000, "Engineering");
console.log(lead.getSummary()); // "Anitha leads Engineering with budget $120,000"

8.5 Modern Asynchronous: Promises & Async / Await

Eliminating callback hell with clean, synchronous-looking asynchronous flows: 

// Simulating an API Fetch with Promise
const fetchUserData = (userId) => {
  return new Promise((resolve, reject) => {
    setTimeout(() => {
      if (userId > 0) resolve({ id: userId, name: "Gokul", role: "Dev" });
      else reject(new Error("Invalid User ID"));
    }, 500);
  });
};

// Async / Await with try / catch
async function loadDashboard() {
  try {
    console.log("Fetching user profile...");
    const user = await fetchUserData(101);
    console.log("User Loaded:", user.name);
  } catch (error) {
    console.error("Failed to load user:", error.message);
  }
}

loadDashboard();
