Chapter 05

JavaScript Operators: Computation, Equality Algorithms, Short-Circuiting & Safety

Operators form the core computational engine of JavaScript. In this chapter, we explore mathematical operations, investigate the internal type-coercion algorithms behind Loose (==) vs Strict (===) equality, master short-circuit evaluation patterns, and examine modern ECMAScript operators like Nullish Coalescing (??) and Optional Chaining (?.).

5.1 Equality Algorithms: Loose (==) vs Strict (===) vs Object.is()

JavaScript provides three distinct equality comparison mechanisms defined in the ECMAScript specification:

1. Loose Equality (==)

Applies the Abstract Equality Comparison Algorithm. If types differ, it coerces operands to common primitives before comparison. 

console.log(5 == "5");       // true
console.log(0 == false);     // true
console.log(null == undefined); // true

2. Strict Equality (===)

Applies the Strict Equality Comparison Algorithm. If types differ, it immediately evaluates to false without coercion. 

console.log(5 === "5");      // false
console.log(0 === false);    // false
console.log(null === undefined); // false

3. SameValue (Object.is())

Distinguishes signed zeros (+0 vs -0) and accurately equates NaN with NaN. 

console.log(Object.is(NaN, NaN)); // true
console.log(Object.is(+0, -0));   // false
console.log(+0 === -0);           // true

The Exhaustive Equality Coercion Matrix

Expression Result Internal Engine Coercion Steps
[] == 0 true Array [] converts via ToPrimitive to "", and Number("") converts to 0.
[] == ![] true ![] evaluates to boolean false. [] == false becomes 0 == 0.
"0" == false true Both sides coerce to numeric value 0 (0 == 0).
null == 0 false Under specification rules, null only loosely equals undefined and nothing else.

5.2 Logical Operators & Short-Circuit Evaluation

In JavaScript, the logical operators && (AND) and || (OR) do not necessarily return boolean values—they return the exact value of the determining operand:

Logical OR (||) Pattern

Returns the first truthy value, or the final operand if all are falsy.

const username = inputUsername || "Anonymous Guest";
console.log("" || "Fallback");      // "Fallback"
console.log("Admin" || "Fallback"); // "Admin"

Logical AND (&&) Pattern

Returns the first falsy value, or the final operand if all are truthy.

const user = { loggedIn: true, token: "JWT_SECURE_TOKEN" };
const authToken = user.loggedIn && user.token;
console.log(authToken); // "JWT_SECURE_TOKEN"

5.3 Modern Safety: Nullish Coalescing (??) & Optional Chaining (?.)

1. The || vs ?? Problem (Preserving 0 and false)

|| checks for falsy values, which inadvertently overwrites valid 0, "", and false inputs! ?? checks strictly for null or undefined. 

const customTimeout = 0; // Valid setting (0 milliseconds)

// Flawed approach using || :
const delay1 = customTimeout || 3000;
console.log("Using || :", delay1); // 3000 ❌ (Overwrote valid 0!)

// Robust approach using ?? :
const delay2 = customTimeout ?? 3000;
console.log("Using ?? :", delay2); // 0    ✅ (Accurately preserved!)

2. Optional Chaining (?.)

Enables safe property navigation, function calls, and array lookups without throwing runtime TypeError: Cannot read properties of undefined. 

const customerOrder = {
  id: 99401,
  customer: {
    name: "Arun"
    // address is omitted
  }
};

// Safe property lookup:
console.log(customerOrder.customer?.address?.zipCode); // undefined (No crash!)

// Safe method invocation:
customerOrder.printInvoice?.(); // Safely ignored if method doesn't exist

// Safe array index access:
const matrix = null;
console.log(matrix?.[0]?.[1]); // undefined

5.4 Top 5 Senior Technical Interview Questions & Answers

Q1: What are the Logical Assignment operators introduced in ES2021?

ES2021 introduced three logical assignment shorthands: x &&= y (assigns y only if x is truthy), x ||= y (assigns y only if x is falsy), and x ??= y (assigns y only if x is null or undefined). They avoid redundant setter invocations when values do not require updates.

Q2: What is the difference between typeof and instanceof?

typeof is a unary operator that returns a primitive type string (e.g. "string", "number"). instanceof is a binary operator that traverses an object's prototype chain to verify whether the constructor's prototype property appears anywhere along the prototype chain (e.g. [] instanceof Array === true).

Q3: What does the void operator do in JavaScript?

The void operator evaluates the given expression and unconditionally returns the primitive value undefined. Commonly used in legacy HTML hyperlinks like javascript:void(0) to prevent page reloads, and in arrow functions to ensure a function explicitly returns undefined.

Q4: What is the unary plus (+) operator used for?

The unary plus operator precedes its operand and attempts to convert it into a numeric primitive. It is the fastest, cleanest idiomatic way in JavaScript to cast numeric strings into Numbers (e.g., +"42" === 42, +true === 1, +false === 0).

Q5: How does the Comma Operator (,) function?

The comma operator evaluates each of its operands from left to right and returns the evaluated value of the last operand (e.g., let x = (1, 2, 3); // x === 3). It is frequently used to execute multiple expressions in for loop updates.
